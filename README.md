# Bash File Manager Collection

This repository contains a collection of bash-based file managers, each with different features and levels of complexity.

## Miller Commander

The `miller_commander` directories contain a series of dual-pane file managers inspired by Midnight Commander. Each numbered subdirectory represents a step in the evolution of the application, with new features and improvements added in each version.

- `miller_commander/`: The initial version.
- `miller_commander2/`: Adds partial UI updates for better performance.
- `miller_commander3/`: A much more detailed and feature-rich version.
- `miller_commander4/`: Improved keybindings and bug fixes.
- `miller_commander5/`: Introduces separate refresh for each pane.
- `miller_commander6/`: Adds file and directory size calculations.

## Noon Commander

The `noonCommander` directory contains a single-pane file manager. It offers a different approach to file management, with a focus on simplicity and ease of use.

- `NoonCommander.sh`: The initial version.
- `NoonCv5.sh`: A more advanced version with improved features.
