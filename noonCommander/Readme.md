The scripts in this directory implement a single-pane file manager called Noon Commander.

`NoonCommander.sh` is the initial version, providing a basic yet functional file manager with features like file preview, editing, and copy/paste.

`NoonCv5.sh` is a more advanced and robust version with several improvements, including:
- Better handling of filenames with spaces and special characters
- A more refined user interface
- Additional keybindings for navigation and file operations
- A help screen
- The ability to mark files for selection
