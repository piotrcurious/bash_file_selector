# Noon Commander

This directory contains Noon Commander, a single-pane file manager written in Bash. The scripts have evolved over time, with each version adding new features and improvements.

## Versions

### NoonC.sh

This is the initial version of Noon Commander. It's a simple, functional file manager with the following features:

-   File indexing and pagination
-   Navigation with arrow keys
-   File selection
-   Rename, delete, copy, and move operations

### NoonCommander.sh

This version introduces a significant number of new features and improvements, including:

-   A more advanced and user-friendly interface
-   File preview for various file types (text, images, PDFs, archives, etc.)
-   File editing with an external editor
-   A clipboard for copy/cut and paste operations
-   File search
-   A detailed file information view

### NoonC_v4_5.sh & NoonCv5.sh

These versions further refine and enhance Noon Commander with features such as:

-   Marking multiple files for selection
-   Bulk operations on marked files (copy, move, delete)
-   Destination favorites for copy and move operations
-   Improved handling of filenames with spaces and special characters
-   A help screen
-   More robust error handling

The `v5` and `v6` scripts are further iterations on this foundation.
